# Music Player — Server

Express + MongoDB API for the Music Player streaming app.

## Stack

Node.js · Express 4 · MongoDB · Mongoose · Clerk · Cloudinary

## Run

```bash
cp .env.example .env
npm install
npm run dev
npm run seed   # optional demo data
```

**http://localhost:3001/api**
