# Music Player — Client

React + Vite frontend for the Music Player streaming app.

## Stack

React 19 · Vite 6 · Redux Toolkit · Clerk · Tailwind CSS 4 · ShadCN UI · React Router 7

## Run

```bash
cp .env.example .env
npm install
npm run dev
```

**http://localhost:3000** — requires API at **http://localhost:3001**

## Environment

```env
VITE_CLERK_PUBLISHABLE_KEY=pk_test_...
# VITE_API_URL=http://localhost:3001/api   # optional override
```
